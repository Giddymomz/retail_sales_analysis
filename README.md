# Retail Sales Analysis

**Question:** Which products, regions & months drive sales?

**Tools:** Python (pandas, matplotlib), Excel

**Data:** 100 sales transactions - Product, Region, Month, Units, Revenue

## Key Findings

1.  **Best Product:** Electronics drives highest revenue
2.  **Best Region:** Nairobi region leads in total sales
3.  **Best Month:** December is peak season - holiday demand
4.  **Insight:** Stock more Electronics in Nairobi in Nov-Dec to maximise sales

## Files

- `data/retail_sales.csv` - Sales dataset (100 rows)
- `analysis.py` - Python analysis code
- `charts/` - Revenue by product, region, month charts
